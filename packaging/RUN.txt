AirPlayServer.NET Native AOT 宿主

本目录是一次发布包。版本和平台写在 VERSION.txt。
程序是 GPL-3.0-only，因为进程内编进了 FairPlay。
对应源码是本仓库里同名的 git tag。包里没有配对种子，也没有密钥材料。

先确认二进制还能跑自检：

  Windows:  AirPlayServer.Host.exe --self-check
  Linux:    chmod +x AirPlayServer.Host
            ./AirPlayServer.Host --self-check

自检通过会打印 self-check ok。--help 打印全部参数。

和 TapClock 一起用（Windows，主路径）：

  1. 先启动 TapClock，让它监听 ATBF（TCP 42125）。点击仍走 TapClock 自己的 TCP 42123。
  2. 再启动本宿主，不要加 --demo-frame：
       AirPlayServer.Host.exe --screen 480x1040 --model iphone-15-pro --tapclock 127.0.0.1:42125
  3. iPhone 在同一局域网里发现接收端并开始镜像。

--screen 是 /info 里的广告分辨率，宿主默认 480x1040。
--model 是 TapClock 点击对齐的竖屏 UIKit 逻辑点（iphone-15-pro 为 393x852），不改广告。
--list-models 打印全部 slug。两个参数可以只写其中一个。

--h265 和 --hevc 是同一个可选开关，默认关闭，只收 H.264。
只有 HEVC 解码器真能打开时，mDNS 和 /info 的 features 才置上第 42 位（SupportsScreenMultiCodec）。
没有解码器时这个开关被忽略，日志用中文和英文写明，手机继续发送 H.264。
这个开关不改默认的 480x1040。较新的苹果设备只有在宣告的分辨率够高时才会改发 HEVC。
例如：
  AirPlayServer.Host.exe --h265 --screen 1290x2796 --model iphone-15-pro-max
Windows 先用 Media Foundation HEVC。没有 CLSID_CMSH265DecoderMFT（也没有可用的硬件 MFT）时改用 FFmpeg。
Linux 上 H.264 和 HEVC 都只走 FFmpeg。

FFmpeg 不在这个压缩包里，也没有链进程序。把共享库放在本目录，或装到系统路径。
认 FFmpeg 4.4 到 8（libavcodec 58–62，libavutil 56–60）。
Windows：从 https://github.com/BtbN/FFmpeg-Builds/releases 下载 win64-lgpl-shared
（win64-gpl-shared 也可以；不要用 static），把 bin 里的 DLL 全部拷到本目录。
至少要有同一版本的 avcodec-*.dll、avutil-*.dll、swresample-*.dll。
Linux：sudo apt-get install ffmpeg
也可以把 libavcodec.so.N、libavutil.so.N、libswresample.so.N 放在本目录。
这些库是 LGPL-2.1-or-later，带 GPL 组件的构建则是 GPL。分发它们时要遵守该构建的许可证。
本程序是 GPL-3.0-only。自动更新不会删除你另外拷进来的 DLL / SO。

Linux 包不创建窗口，也不包含 Media Foundation。没有 FFmpeg 时可以用 --demo-frame 检查导出。
linux-x64 包里的 airplayserver.service 是 systemd 草稿，不含 --seed。
把 AirPlayServer.Host 拷到 /usr/local/bin/ 后再启用。
这个二进制在 GitHub 的 ubuntu-latest 上构建，需要兼容的 glibc。

--seed 只留在内存里，不要写进单元文件或脚本后提交。
发布包不含 .pdb / .dbg 调试符号，运行不需要它们。

启动时会检查 GitHub 上这个仓库的最新稳定版（不含预发布）。
版本以本目录的 VERSION.txt 为准。有较新版本时，下载同一平台的 zip，
能对上 SHA256SUMS.txt 就先校验，再替换本目录里的程序和这些说明文件，然后重新启动。
检查失败、校验失败或目录不可写时，只记日志，继续跑当前这个程序。
不想检查时加上 --no-update。只检查、不启动接收端时用 --check-update 或 --update。
已经是最新稳定版时，这两条只打印版本并退出。
--version 打印版本，不访问网络。
公开的 Release 不需要令牌。私有仓库请设置环境变量 GITHUB_TOKEN 或 GH_TOKEN。
